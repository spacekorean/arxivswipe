arXiv Swipe

arXiv에 새로 올라온 논문을 SNS 피드처럼 위아래로 넘겨보는 샘플입니다.

  • 위/아래 스와이프 — 다음·이전 논문 (데스크톱은 ↑↓ 방향키)
  • 더블탭 — 저장 / 저장 해제
  • 카드 탭 — 초록 펼치기·접기
  • 상단 탭 — 분야 전환, ★ 는 저장한 논문

GitHub Actions가 3시간마다 arXiv API에서 신착 논문을 수집해 정적 JSON으로 저장합니다. 내 컴퓨터가 켜져 있을 필요는 없습니다. 상단 새로고침 버튼은 그 최신 JSON을 다시 받아옵니다.
